## About the Project

[![Website Preview](public/og-image.png)](https://www.mathwithsonya.ru/)

**Math&Sonya** is a responsive website for a mathematics tutor, built with Next.js, React, and TypeScript.

The website content can be fetched from MockAPI. If the external data source is not configured or unavailable, the application falls back to its built-in default content, keeping the main sections accessible.

<p align="right">(<a href="#readme-top">Back to top</a>)</p>

### Features

- Home page with information about the tutor
- About section covering education, experience, and teaching approach
- Lesson formats: online, at the tutor's place, and at the student's home
- Information about lesson prices, terms, and benefits
- Photo gallery with image viewing
- Review carousel featuring students and parents
- Contact details, including phone, email, and Telegram
- Lesson booking form protected by reCAPTCHA
- Map showing the tutor's location and service areas
- Responsive layout for mobile devices and desktop computers
- SEO metadata, Open Graph tags, sitemap, and robots.txt

### Technologies

[![Next.js][next.js]][next-url]
[![React][react.js]][react-url]
[![TypeScript][typescript.ts]][typescript-url]
[![Material UI][mui]][mui-url]
[![Sass][sass]][sass-url]

- **Next.js 15** — React framework and server-side rendering
- **React 19** — user interface library
- **TypeScript** — static typing
- **Material UI** and **Emotion** — UI components and styling
- **Sass** — modular stylesheets
- **Swiper** — sliders and carousels
- **Yet Another React Lightbox** and **React Photo Album** — image gallery
- **Motion** — animations
- **Axios** — HTTP requests
- **Google reCAPTCHA** — protection against automated form submissions
- **next-sitemap** — sitemap generation
